# ICBM 3D Automotive Studio - 차량 3D 모델링 및 부품 인터랙티브 검측 시스템

사용자가 업로드한 **세단 블루프린트 도면(Kia K5 스타일)**을 기반으로 제작된 **실시간 3D 인터랙티브 차량 모델링 및 부품 확대(Zoom-in) 검측 웹 애플리케이션**입니다.

---

## 🌟 주요 개편 및 구현 사항

### 1. 생산관리 / 현황 / 공급업체 메뉴 제거 및 전체 3D 스튜디오 확장
- 기존 복잡했던 좌측 메뉴(생산관리, 현황, 공급업체) 및 우측 패널을 전면 제거하여 **100% 풀스크린 3D 뷰포트**로 개편했습니다.
- 마우스 조작을 방해하지 않는 상단 슬림 네비게이션 툴바와 하단 플로팅 글래스모피즘(Glassmorphism) 상세 카드로 직관성을 극대화했습니다.

### 2. 세단 블루프린트 1:1 기반 정밀 3D 모델링
- 업로드된 사이드 뷰 블루프린트의 차체 프로포션(낮고 날렵한 프론트 노즈, 타이거 노즈 그릴, A필러와 유려한 패스트백 루프라인, 덕테일 트렁크 리드, 휠베이스, 10-스포크 알로이 휠)을 3D 메쉬로 구현했습니다.
- **실시간 마우스 조작 (OrbitControls)**:
  - **좌클릭 드래그**: 360도 자유 3D 회전 (수평/수직 회전)
  - **마우스 휠**: 자유 확대 / 축소 (Zoom In / Out)
  - **우클릭 드래그**: 3D 공간 횡이동 (Pan)
  - **360° 자동 회전 모드**: 상단 우측 `[360° 회전]` 버튼 클릭 시 쇼룸 스타일 자동 턴테이블 회전

### 3. 부품 선택 시 시네마틱 3D 카메라 줌인 & 후드 오픈
- **엔진룸 [엔진] 선택 시**:
  - 3D 카메라가 전면 엔진룸으로 **시네마틱 줌인**됩니다.
  - **자동차 후드(Hood)가 3D 공간에서 위로 부드럽게 열리며(Open Hood)**, 내부의 **V6 실린더 블록, 인테이크 매니폴드, 트윈 터보차저, 라디에이터, 고압 연료펌프**가 입체적으로 노출됩니다.
  - `[연료펌프: 부족 3일 ⚠️]`, `[트윈스크롤 터보차저: 정상]` 3D 서브 핀이 표시됩니다.
- **전륜 브레이크 [브레이크] 선택 시**:
  - 카메라가 전륜 휠 브레이크로 근접 비행하여 **360mm 대형 벤틸레이티드 로터 디스크**와 **레드 4-피스톤 스포츠 캘리퍼**, `[브레이크 패드: 지연 7일 ⚠️]` 핀이 상세 표시됩니다.
- **후륜 바퀴 [바퀴 & 휠] 선택 시**:
  - 10-스포크 단조 알로이 휠과 **245/40R19 타이어 (지연 2일)**, **TPMS 센서**로 확대됩니다.
- **전장 [전장 & 배터리] 선택 시**:
  - 차체 플로어 하부의 **48V 리튬이온 배터리 팩 (부족 5일분 ⚠️)**과 중앙 ECU 하네스로 확대됩니다.
- **복귀**:
  - 우측 상단 `[⟲ 전체 외형 시점으로 복귀]` 버튼을 누르거나 캔버스를 더블 클릭하면 즉시 전체 차량 외형 뷰로 복귀하며 열렸던 후드가 자동으로 닫힙니다.

### 4. 3D 공간 연동 인터랙티브 핀 (Screen Projection)
- 차량의 3D 공간 좌표에 부착된 핀 뱃지(`엔진`, `브레이크`, `바퀴`, `전장`, `차체`)가 **사용자가 마우스로 차를 돌릴 때마다 3D 좌표를 2D 화면 좌표로 실시간 계산하여 자연스럽게 따라다닙니다.**
- 핀을 직접 클릭하여 부품으로 줌인할 수도 있습니다.

### 5. 외장 도장 컬러 커스텀 & X-Ray 투시 모드
- **도장 색상 변경**: 상단 팔레트에서 스노우 화이트 펄, 티타늄 실버, 미드나잇 블루, 크림슨 레드, 스텔스 블랙 등 5가지 메탈릭 컬러를 즉시 적용할 수 있습니다.
- **X-Ray 투시 모드**: `[X-Ray 투시]` 클릭 시 외장 바디가 반투명해지며 내부 섀시 골격과 파워트레인을 상시 투시할 수 있습니다.
